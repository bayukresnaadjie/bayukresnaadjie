## 🧑‍💻 About Me

Saya seorang **Laravel & Full-Stack Web Developer** berbasis di Yogyakarta, Indonesia. Berpengalaman membangun aplikasi web skala nyata — dari sistem manajemen, REST API, hingga aplikasi kasir dan perpustakaan digital. Saya fokus pada kode yang bersih, terstruktur, dan siap produksi.

- 🔭 Sedang membangun portofolio proyek Laravel fullstack
